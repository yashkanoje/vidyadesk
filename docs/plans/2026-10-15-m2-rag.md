# M2 RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each institute add its own documents (prospectus, brochures, rules) and let the agent answer questions from them through a `search_docs` tool, with a measured retrieval score.

**Architecture:** A document is read (PDF or text), split into passages of about 100 words, embedded with a small local model, and stored in PostgreSQL with pgvector, tagged with its `institute_id`. The agent's new `search_docs(query)` tool embeds an English query and returns the institute's 4 nearest passages above a similarity floor. Structured facts (fees, batches) stay in the prompt exactly as in M1.

**Tech Stack:** pgvector 0.8.7 (server, built from source on 15 Oct 2026) with the `pgvector` Python package (0.5), fastembed 0.9 with `BAAI/bge-small-en-v1.5`, pypdf, fpdf2 (tests only). Everything else as M1.

**Spec:** `docs/specs/2026-10-13-lead-agent-design.md`, Sections 6 (documents and chunks), 7 (RAG), 13 (testing), 14 (M2 milestone).

## Global Constraints

- Embedding model: `BAAI/bge-small-en-v1.5`, 384 dimensions, run locally through fastembed. No API key. It downloads once (about 70 MB) into `data/models/`, which is git-ignored.
- Accepted files: PDF, `.txt`, `.md`, up to 10 MB. A PDF with no extractable text is stored with status `failed` and the reason "no text found".
- `search_docs` returns at most 4 passages, nearest by cosine distance, always filtered by `institute_id`, and drops passages below `RAG_MIN_SIMILARITY`. Nothing left: the tool says so and the agent hands off.
- The similarity floor is set from the retrieval test set (Task 7), never guessed. Target: the expected passage is in the top 3 for at least 80% of questions.
- Automatic tests never download or run the real model: a fake embedder is used unless a test is marked `model`. Model tests run with `RUN_MODEL_TESTS=1`.
- `create_tables()` runs `CREATE EXTENSION IF NOT EXISTS vector`, which needs a database superuser (the local `postgres` user is one; so is CI's).
- Unchanged from M1: synchronous code, one process, no hardcoded absolute paths, never log a token, tests only against a database whose name ends in `_test`.
- Shell commands are PowerShell, run from `PROJECT LEAD AGENT/`.

## Review Focus

1. **The same file uploaded again** (an owner updates the prospectus). Expected: the new version replaces the old one; the agent never sees two copies. (Task 4)
2. **A text file saved in a Windows code page** rather than UTF-8. Expected: it is still added; odd characters are replaced, not fatal. (Task 4)
3. **A question asked in Hindi or Odia.** Expected: the agent searches in English and answers in the user's language. (Task 8, behaviour check `doc-bus-hindi`)
4. **An institute that is deleted.** Expected: its documents and passages go with it. (Task 2)
5. **A question the documents do not cover** (hostel). Expected: no invented answer; handoff, as in M1. (Tasks 7 and 8: unanswerable retrieval cases and the existing `en-missing-hostel` check)

## Ruling taken while planning

Spec Section 7 says passages of about 500 tokens with a 50-token overlap. This plan uses **about 100 words (roughly 130 tokens) with a 20-word overlap.** Coaching-institute documents are short and split into small sections (refunds, transport, scholarship test); 500-token passages would merge most of a prospectus into two or three passages, so every search would "find" the answer and the retrieval score would mean nothing. Task 9 records this in the spec. Cost if wrong: more passages per document, which is cheap at this size.

```python
class FakeEmbedder:
    """Stands in for the real model: texts that share words get similar vectors. Deterministic and instant."""

    dims = 384

    def _vector(self, text):
        vector = [0.0] * self.dims
        for word in re.findall(r"[a-z0-9]+", text.lower()):
            vector[int(hashlib.md5(word.encode()).hexdigest(), 16) % self.dims] += 1.0
        norm = math.sqrt(sum(x * x for x in vector)) or 1.0
        return [x / norm for x in vector]

    def passages(self, texts):
        return [self._vector(text) for text in texts]

    def query(self, text):
        return self._vector(text)
```

```python
"""Text embeddings for document search. The model runs on this machine: no API key, no per-use cost."""
from functools import lru_cache
from pathlib import Path

MODEL = "BAAI/bge-small-en-v1.5"
DIMS = 384
CACHE_DIR = Path(__file__).resolve().parents[2] / "data" / "models"  # data/ is git-ignored; about 70 MB


class FastEmbedder:
    def __init__(self):
        from fastembed import TextEmbedding  # imported here: it is slow to load, and tests use a fake

        self._model = TextEmbedding(model_name=MODEL, cache_dir=str(CACHE_DIR))

    def passages(self, texts):
        return [vector.tolist() for vector in self._model.embed(list(texts))]

    def query(self, text):
        return self.passages([text])[0]


@lru_cache
def get_embedder():
    return FastEmbedder()
```

```python
    session.add_all(

        for i, (text, vector) in enumerate(zip(texts, vectors, strict=True))
    )


def documents_for(session, institute_id):
    return list(session.scalars(select(Document).where(Document.institute_id == institute_id).order_by(Document.id)))


def get_document(session, institute_id, document_id):

def documents_named(session, institute_id, filename):

    rows = session.execute(

        .join(Document, Document.id == Chunk.document_id)
        .where(Chunk.institute_id == institute_id, Document.status == "ready")
        .order_by(distance)
        .limit(k)
    ).all()
    return [(chunk, float(dist), filename) for chunk, dist, filename in rows]
```

`leadagent/rag/chunk.py`:

```python
import re


def chunk_text(text, max_words=100, overlap_words=20):
    """Split text into passages of about max_words words, breaking between paragraphs where possible.

    A paragraph longer than max_words is cut into windows that overlap by overlap_words. When a new passage
    starts, it repeats the previous passage's last paragraph if that is short (overlap_words or fewer), so a
    heading stays with the text after it. Passages can therefore reach max_words + overlap_words.
    """
    pieces = []
    for paragraph in re.split(r"\n\s*\n", text):
        words = paragraph.split()
        while len(words) > max_words:
            pieces.append(" ".join(words[:max_words]))
            words = words[max_words - overlap_words :]
        if words:
            pieces.append(" ".join(words))

    passages, current, size = [], [], 0
    for piece in pieces:
        count = len(piece.split())
        if current and size + count > max_words:
            passages.append("\n\n".join(current))
            tail = current[-1]
            current, size = ([tail], len(tail.split())) if len(tail.split()) <= overlap_words else ([], 0)
        current.append(piece)
        size += count
    if current:
        passages.append("\n\n".join(current))
    return passages
```

```python
from pypdf import PdfReader

from leadagent.rag import embed
from leadagent.rag.chunk import chunk_text
from leadagent.store import repo
from leadagent.store.db import create_tables, session_scope

MAX_BYTES = 10 * 1024 * 1024
TEXT_SUFFIXES = {".txt", ".md"}


class IngestError(ValueError):
    """The file was refused before anything was stored. The message is safe to show to an owner."""


def extract_text(path: Path) -> str:
    if path.suffix.lower() == ".pdf":
        return "\n\n".join(page.extract_text() or "" for page in PdfReader(str(path)).pages)
    return path.read_text(encoding="utf-8", errors="replace")


def ingest(session, institute_id, path):
    path = Path(path)
    if path.suffix.lower() not in TEXT_SUFFIXES | {".pdf"}:
        raise IngestError(f"{path.name}: only PDF, .txt and .md files are accepted")
    if path.stat().st_size > MAX_BYTES:
        raise IngestError(f"{path.name} is larger than 10 MB")
    for old in repo.documents_named(session, institute_id, path.name):  # a new version replaces the old one
        repo.delete_document(session, old)
    document = repo.add_document(session, institute_id, path.name)
    try:
        text = extract_text(path)
    except Exception as exc:  # a damaged or password-protected PDF
        repo.mark_document_failed(session, document, f"could not read the file ({type(exc).__name__})")
        return document
    passages = chunk_text(text)
    if not passages:
        # shortcut: scanned PDFs are refused, add OCR when an institute's brochure is a scan (spec Section 15)
        repo.mark_document_failed(session, document, "no text found (a scanned PDF needs OCR, which is not supported yet)")
        return document
    repo.add_chunks(session, document, passages, embed.get_embedder().passages(passages))
    return document


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(prog="leadagent.rag.ingest")
    parser.add_argument("--institute", required=True, help="the institute's slug")
    action = parser.add_mutually_exclusive_group(required=True)
    action.add_argument("file", nargs="?", help="a PDF, .txt or .md file to add")
    action.add_argument("--list", action="store_true", help="list this institute's documents")
    action.add_argument("--delete", type=int, metavar="DOCUMENT_ID", help="delete a document and its passages")
    args = parser.parse_args(argv)

    create_tables()
    with session_scope() as session:
        institute = repo.institute_by_slug(session, args.institute)
        if institute is None:
            print(f"Error: No institute with slug {args.institute!r}", file=sys.stderr)
            return 1
        if args.list:
            for document in repo.documents_for(session, institute.id):
                reason = f"  ({document.error})" if document.error else ""
                print(f"{document.id}  {document.filename}  {document.status}{reason}")
            return 0
        if args.delete is not None:
            document = repo.get_document(session, institute.id, args.delete)
            if document is None:
                print(f"Error: No document {args.delete} for this institute", file=sys.stderr)
                return 1
            repo.delete_document(session, document)
            print(f"Document {args.delete} and its passages are deleted.")
            return 0
        try:
            document = ingest(session, institute.id, args.file)
        except (IngestError, FileNotFoundError) as exc:
            print(f"Error: {exc}", file=sys.stderr)
            return 1
        reason = f" ({document.error})" if document.error else ""
        print(f"Added {document.filename} as document {document.id}: {document.status}{reason}")
        return 0 if document.status == "ready" else 1
```

```python
from dataclasses import dataclass

from leadagent.rag import embed
from leadagent.settings import get_settings
from leadagent.store import repo


@dataclass(frozen=True)
class Passage:
    document: str  # the file it came from
    text: str
    similarity: float  # cosine similarity to the question; 1.0 means the same meaning


def search(session, institute_id, query, k=4, min_similarity=None):
    """This institute's passages nearest in meaning to the query, best first, above the similarity floor."""
    floor = get_settings().rag_min_similarity if min_similarity is None else min_similarity
    vector = embed.get_embedder().query(query)
    passages = [
        Passage(filename, chunk.text, 1.0 - distance)
        for chunk, distance, filename in repo.nearest_chunks(session, institute_id, vector, k)
    ]
    return [p for p in passages if p.similarity >= floor]
```

```python
def passage_hit(passages, phrase) -> bool:
    return any(phrase.lower() in passage.lower() for passage in passages)


def suggest_floor(answerable, unanswerable) -> float:
    """The similarity floor that sorts the most questions correctly into "answer" and "hand off".

    Each observed score is tried as the floor; ties go to the lower floor.
    """
    best, best_correct = 0.0, -1
    for floor in sorted(set(answerable) | set(unanswerable)):
        correct = sum(score >= floor for score in answerable) + sum(score < floor for score in unanswerable)
        if correct > best_correct:
            best, best_correct = floor, correct
    return round(best, 3)
```

```python
            name="Retrieval test",
            facts=load_facts_file(EXAMPLES / "brightpath.yaml"),
            telegram_token="unused",
        ).id
        status = ingest(session, institute_id, EXAMPLES / "brightpath-prospectus.txt").status
    print(f"prospectus: {status}")
    hits, answerable, unanswerable, missed = 0, [], [], []
    try:
        with session_scope() as session:
            for case in cases:
                passages = search(session, institute_id, case["question"], k=3, min_similarity=0.0)
                top = passages[0].similarity if passages else 0.0
                if case["expect"] is None:
                    unanswerable.append(top)
                    continue
                answerable.append(top)
                if passage_hit([p.text for p in passages], case["expect"]):
                    hits += 1
                else:
                    missed.append(case["question"])
    finally:
        with session_scope() as session:
            session.delete(repo.get_institute(session, institute_id))  # its documents and passages go with it
    rate = hits / len(answerable)
    print(f"expected passage in the top 3: {hits} of {len(answerable)} = {rate:.0%} (target {TARGET:.0%})")
    for question in missed:
        print(f"  missed: {question}")
    print(f"best similarity, questions the prospectus answers: lowest {min(answerable):.3f}")
    print(f"best similarity, questions it does not answer:   highest {max(unanswerable):.3f}")
    print(f"suggested RAG_MIN_SIMILARITY: {suggest_floor(answerable, unanswerable)}")
    return 0 if rate >= TARGET else 1


if __name__ == "__main__":
    sys.exit(main())
```
