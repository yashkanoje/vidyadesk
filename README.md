# PROJECT LEAD AGENT

An AI agent that answers student and parent enquiries for coaching institutes on WhatsApp
and Telegram, records each one as a lead, and makes sure the owner follows up.

**Status:** design stage. No code yet.

- Design spec: [docs/specs/2026-10-13-lead-agent-design.md](docs/specs/2026-10-13-lead-agent-design.md)
- Stack: Python, FastAPI, LangGraph, Claude Haiku 4.5, PostgreSQL with pgvector
- Milestones: M1 core agent, M2 RAG, M3 dashboard
- Refinement backlog: Section 15 of the spec
